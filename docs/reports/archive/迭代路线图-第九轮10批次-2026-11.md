# 迭代路线图 — 第九轮 10 批次（2026-11 · 体验深化）

> 主题：**数据可视化 · 监控闭环 · 用户触点打磨**
> 前置：第八轮（R2 生态收口 + 发版 v14.7.x）完成后启动。
> 方向原则：不新增大子系统——在既有数据资产（行为画像/收藏/限免/下载历史/
> 评分缓存）上做可视化与触点深化；CWS 上架为用户操作项，本轮提供物料批。

---

## 批次 1【监控】ITAD 史低与价格历史深化

- favorites 已有最低价——增加**史低标记**（历史最低 vs 当前价，ITAD overview
  端点已有）与降价幅度百分比显示
- 收藏行 hover 展示近 90 天价格走势（复用 itadLowestCache 采样，不做新存储）
- 验收：mock ITAD 响应断言史低标记与幅度；无 Key 零请求不变
- 预估：中 · 风险：低

## 批次 2【监控】限免监控增强——错过统计与日历视图

- 限免历史已存——dashboard 增加"错过统计"（监控开启期间错过的限免数/价值）
- freegames 页月历视图（当月限免分布，hover 详情）
- 验收：mock 数据断言统计与渲染；预估中 · 风险：低

## 批次 3【可视化】行为画像雷达图

- dashboard 游戏表已有画像数据（clickScore/downloadScore/keywordMatch/
  steamRating）——Top10 游戏画像雷达图（SVG，零依赖，与趋势图同风格）
- hover 显示四维明细；点击跳游戏表过滤
- 验收：SVG 渲染断言 + visual 基线更新；预估中 · 风险：低

## 批次 4【可视化】下载历史统计视图

- 下载历史已有列表——增加聚合视图（按站/按游戏 TopN、近 30 天趋势）
- 与行为画像的 downloadScore 口径互验（数据同源不同视角）
- 验收：聚合计算纯函数单测 + 渲染断言；预估小 · 风险：低

## 批次 5【UX】过滤预设跨站管理与导出

- 过滤预设现按 host 隔离（grFilterPresets:<host>）——增加"应用到其他站"
  与 JSON 导出/导入（随规则包通道顺带，v2 schema 可选段）
- 验收：复制/导入往返单测；预估小 · 风险：低

## 批次 6【UX】Steam 页反向深链

- 内嵌 Steam 卡/详情浮窗增加"在下载站搜索"入口（store 页 → 打开 trackedSites
  搜索该游戏新标签）——数据回流闭环的反向触点
- 仅 trackedSites 非空时渲染；站名来自 adapter 规则
- 验收：入口渲染门控断言；预估小 · 风险：低

## 批次 7【UX】欢迎页引导刷新至 v14 特性

- welcome 4 步引导内容停留在早期版本——更新为当前核心流（徽章/浮窗/过滤
  /词表生态一句话）；changelog 渲染已动态无需动
- 验收：E2E 引导 4 步跳转既有断言全绿 + 文案更新；预估小 · 风险：低

## 批次 8【平台】SidePanel 操作入口

- SidePanel 当前页游戏快照已有——增加操作行（刷新/收藏/打开浮窗设置）
  与历史最近 5 游戏点击跳转
- 验收：探针 8/8 既有断言 + 新增操作断言；预估中 · 风险：低

## 批次 9【CWS 物料】上架物料批（用户操作的前置准备）

- STORE.md 刷新至 v14.7 卖点（词表生态/自愈/性能数字）；截图清单核对
- 隐私权限说明复核（manifest 最小权限审计——v14.5.0 无缺口结论复核）
- diagnostics.js 迁出评估重试（扫描器误报 ×3 阻断——换独立目录+注释策略
  再试一次，仍阻则维持原位记档）
- 验收：物料齐备交用户操作；预估小 · 风险：低（扫描阻断为已知风险）

## 批次 10【收尾】阶段回顾

## 贯穿纪律

1. 每批 gate 全绿 + 棘轮不升；visual 涉及 dashboard/freegames 的批次同步基线
2. 新可视化全部零依赖 SVG（趋势图先例，不引图表库）
3. 监控类增强无 Key/无数据时零请求零渲染（既有纪律）
4. 每批独立 commit
